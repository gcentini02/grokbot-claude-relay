# Changelog

## 0.1.0

First public release.

- CLI and MCP (stdio) server: send, inbox, ack, redact, tasks, task_update, health, digest.
- Local SQLite storage with per-participant token files.
- Body size cap, send rate cap, idempotency keys.
- Owner-authority refusal, tripwire alerts, redaction.
- Optional wake-up webhook and folder-limited attachments.
- Helper scripts for Linux/X11.
